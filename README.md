# 🚗 Driver Distraction Detection System

An AI-powered computer vision project that detects distracted driving behaviors using deep learning.

## 📌 Project Overview

Driver distraction is a major cause of road accidents. This project explores deep learning models to classify driver activities from images and identify potentially distracted driving behavior.

## 🧠 Models Implemented

- Custom Convolutional Neural Network (CNN)
- MobileNetV2
- EfficientNetB0

## 🛠️ Tech Stack

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## 📊 Model Performance

| Model | Validation Accuracy |
|---|---:|
| Custom CNN | 68.87% |
| MobileNetV2 | 94.27% |
| EfficientNetB0 | 93.18% |

*These are the results from the current notebook validation split; they should be re-evaluated using a driver-wise split before being treated as final performance.*

## 📂 Dataset

State Farm Distracted Driver Detection dataset from Kaggle.

Dataset: https://www.kaggle.com/competitions/state-farm-distracted-driver-detection

The dataset is not included in this repository.

## ▶️ How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Download the dataset from Kaggle.
4. Open the notebook in Google Colab or Jupyter Notebook.
5. Run the cells in sequence.
